# Context maintenance

Maintainer: repository owner. Context handling reviewed: 2026-10-22.

This repository's existing source and documents retain their own dates and evidence status. Static packages and reports are historical snapshots; plans are proposals; a local test result does not certify deployment. Before operational use, recheck the current owning source revision, test or measurement environment, assumptions and outstanding review gates. Do not update old evidence dates merely to make them appear current.

Use the [canonical company brain](https://github.com/carrieros-ai/carrieros-brain) for accepted, non-expired organizational decisions. Keep this repository's purpose-specific context lightweight. No new general-purpose brain or automatic memory promotion is required.

Follow [CONTEXT_BOUNDARY.md](CONTEXT_BOUNDARY.md). Run `python3 scripts/check-context-boundary.py` before review. Frozen packages and reports must be versioned intentionally rather than silently rewritten. Cluster system designs may not be copied into a report, guide, archive or graph.
